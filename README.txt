HOW TO USE
1. Upload all these files into your GitHub repository folder:
   wdd131/project/
2. Keep the filenames exactly as shown.
3. Open project/index.html to preview the website locally or through GitHub Pages.
4. Your GitHub Pages project URL should be similar to:
   https://ayomideayodeji1004.github.io/wdd131/project/

IMPORTANT
- The forms are front-end demonstrations. They save entries to the visitor's own browser using localStorage; they do not send information to a real repair shop.
- The displayed repair prices are illustrative examples, not confirmed prices. Update them to accurate prices before presenting the site as a real business website.
- Read and test the code before submitting. Your course may require you to explain your HTML, CSS, and JavaScript.
- Check your instructor's complete project instructions and audit tool before submission.
- Do not put real passwords or sensitive information into the demo forms.

REQUIREMENTS INCLUDED
- At least three main pages, plus references page
- Shared responsive navigation and consistent visual theme
- Semantic HTML and accessible labels
- Responsive CSS, focus states, reduced-motion support
- Form validation and DOM interactions
- Multiple JavaScript functions, conditional branching, objects, arrays and array methods
- Template literals for generated output messages
- localStorage usage
- Search/filter interaction
